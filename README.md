# selenium-practice

Учебные автотесты на JavaScript с Selenium WebDriver и встроенным тест-раннером Node.js (`node:test`).

## Что внутри

- `app/` — учебные веб-страницы: вход, счётчик, калькулятор, список дел, регистрация, пользователи.
- `tests/` — автотесты для каждой страницы.
- `first-script.js` — первый скрипт: Selenium сам открывает браузер и входит на страницу.

## Требования

- Node.js 22 или новее
- Google Chrome (драйвер Selenium скачает сам)

## Запуск

```bash
npm install
npm test
```
